# Database Seeders

This directory contains seeders for populating the database with test/demo data for development and testing purposes.

## Overview

The seeders create sample data for the following models:
- **Device**: Energy meter devices with realistic specifications
- **CommunicationEndpoint**: Connection configurations (TCP/SERIAL) for devices
- **DeviceAddressing**: DLMS client/server addressing configurations
- **NegotiatedParams**: HDLC/DLMS negotiated connection parameters

## Usage

### Running All Seeders

```bash
# Set your database URL
export DATABASE_URL="postgresql://user:password@localhost:5432/dlms_meter_communication"

# Run all seeders
python -m dlms_meter_communication.seeders.run_seeders
```

### Using Seeders Programmatically

```python
from sqlmodel import create_engine, Session
from dlms_meter_communication.seeders import DatabaseSeeder

# Create database session
engine = create_engine(database_url)
session = Session(engine)

# Run all seeders
results = DatabaseSeeder.seed_all(session)

# Access created records
devices = results['devices']
endpoints = results['endpoints']
addressing = results['addressing']
params = results['negotiated_params']
```

### Running Individual Seeders

```python
from sqlmodel import Session
from dlms_meter_communication.seeders import (
    DeviceSeeder,
    CommunicationEndpointSeeder,
    DeviceAddressingSeeder,
    NegotiatedParamsSeeder
)

# Seed only devices
devices = DeviceSeeder.seed(session)

# Seed endpoints (requires devices)
endpoints = CommunicationEndpointSeeder.seed(session, devices)

# Seed addressing (requires endpoints)
addressing = DeviceAddressingSeeder.seed(session, endpoints)

# Seed negotiated params (requires devices and endpoints)
params = NegotiatedParamsSeeder.seed(session, devices, endpoints)
```

## Seeded Data

### Devices (5 records)
- **Main Building Meter**: Landis+Gyr E650 - Primary building monitoring
- **Secondary Building Meter**: Elster A1800 - Backup monitoring
- **Solar Panel Meter**: Iskra MT880 - Bidirectional solar monitoring
- **Industrial Facility Meter**: Schneider PM5560 - Three-phase industrial
- **Test Lab Meter**: Generic DLMS-TEST - Development/testing

### Communication Endpoints (8 records)
- Mix of TCP and SERIAL connections
- Both WRAPPER and HDLC_TUNNELING profiles
- Primary and backup connections for critical devices
- Various baud rates (9600, 19200, 115200) for serial
- Different network configurations (LAN, industrial network, localhost)

### Device Addressing (8 records)
- Various client addresses: 16 (Public), 1 (Management), 32 (Data read), etc.
- Standard server addresses: 1, 17, 33, 49, 65
- Mix of Logical Name and Short Name referencing

### Negotiated Parameters (5 records)
- TCP configurations: Large frame sizes (2048 bytes), max PDU (65535)
- Serial configurations: Smaller frames (128 bytes), limited PDU (512)
- Standard DLMS window size (1)

## Dependencies

The seeders must be run in the following order due to foreign key relationships:

1. **DeviceSeeder** (no dependencies)
2. **CommunicationEndpointSeeder** (requires Device)
3. **DeviceAddressingSeeder** (requires CommunicationEndpoint)
4. **NegotiatedParamsSeeder** (requires Device and CommunicationEndpoint)

The `DatabaseSeeder.seed_all()` method handles this ordering automatically.

## Notes

- All UUIDs are auto-generated by the database
- Timestamps (created_at, updated_at) are automatically set
- Serial numbers are unique across devices
- Communication endpoints enforce validation constraints:
  - TCP connections require `ip` and `port`
  - SERIAL connections require `serial_port` and `baud_rate`
- Each device can have multiple endpoints (primary and backup)
- Negotiated params use typical DLMS values based on connection type

## Clearing Seeded Data

To remove all seeded data, delete records in reverse order of dependencies:

```sql
DELETE FROM negotiated_params;
DELETE FROM device_addressing;
DELETE FROM comm_endpoints;
DELETE FROM devices;
```

Or use CASCADE delete from devices:

```sql
DELETE FROM devices;  -- Will cascade to all related records
```
